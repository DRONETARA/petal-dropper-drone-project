# P2 digital validation

- 46 delivered printable STL binaries checked independently: zero boundary/nonmanifold edges, zero degenerate triangles, positive signed volume, valid binary length.
- Each printable part is one connected solid and fits a 220 mm cube. Coordinates are millimetres.
- 91 keeper states and 96 door states, sampled at 1°: no surface intersections in the stated moving-versus-fixed-print/landing scope.
- Nominal minimum sampled printed door-to-ground gap: 176.312 mm. This is upright model geometry, not flight clearance.
- Upper/lower plate DXFs checked against circular-hole lists: 32/56 holes. Upper plate has four rectangular battery strap slots. Both outer outlines are 400 ×400 mm.
- Closed, open and underside renders visually inspected; final P2 file opened in the user's Blender application. The prior unsaved P1 UI scene was copied to the work folder before replacement.
- No physical load, release, material, electrical, thrust or flight test was performed. Read the qualification worksheet and interface limitations in the guide.
